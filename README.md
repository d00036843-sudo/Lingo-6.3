# Lingo — переводчик по фото

Статический сайт: `index.html`, `style.css`, `app.js`, `sw.js`, `manifest.webmanifest`, иконки.

**GitHub Pages:** загрузите все файлы в корень репозитория → Settings → Pages → Branch `main` / root → Save.

**Установка как приложение:** откройте ссылку на телефоне или в Chrome → «Установить» / «На главный экран».

**Перевод:**
- **Index-Translate** (нейросеть Bilibili, 150 языков) — бесплатно, без ключа
- Google / Lingva / MyMemory — запасные бесплатные движки
- DeepSeek / Google Cloud — опционально, если вставить ключ в ⚙ Настройки

**Важно:** не открывайте `index.html` напрямую из папки (file://). Используйте локальный сервер или GitHub Pages — иначе OCR и нейросеть могут не работать.
